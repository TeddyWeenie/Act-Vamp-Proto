# 녹턴: 세 개의 서약

뱀파이어 귀족, 늑대인간 장교, 인간 기공사가 함께 진실을 캐는 반실시간 파티 RPG입니다.
3D 배경 위에 2D 캐릭터를 세운 2.5D 화면으로 다시 만들고 있습니다. 목표 플랫폼은 웹과 Steam입니다.

지금은 제1장의 첫 전투까지 해 볼 수 있습니다. 리시엔으로 마을 광장을 걸어 기록관 오린에게 말을 걸고, 세 가지 지원 가운데 하나를 고른 뒤,
볼프·에다와 함께 광장 동쪽의 동력로로 가면 걷던 자리에서 대형만 다시 잡아 첫 전투가 벌어집니다.
볼프, 에다, 오린, 적, 동력로는 아직 "임시" 이름표가 붙은 임시 그림입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |

## 조작

- `W` `A` `S` `D` 또는 방향키, 바닥 클릭: 이동
- `E`: 가까이 있는 사람에게 말 걸기
- 대화: `Space`나 클릭으로 넘기고, 선택지는 숫자 키나 클릭으로 고릅니다
- 전투: `↑` `↓`와 `Enter`(또는 숫자 `1`~`5`, 클릭)로 명령을 고릅니다. 적 하나를 노리는 명령은 `↑` `↓`로 대상을 바꾸고 `Enter`로 정하며(적을 직접 눌러도 됩니다), `Esc`로 돌아갑니다. `Shift`를 누르고 있으면 모두의 정보가 펼쳐집니다
- 휠: 확대·축소

전투 대형은 아군이 왼쪽, 적이 오른쪽에 섭니다. 전투 중에는 캐릭터 발밑에 막대 두 줄(HP, 배리어)만 보이다가, 차례가 오거나 겨눠지거나 마우스를 올리면 옆에 이름표로 펼쳐집니다. 차례가 온 아군의 명령은 그 캐릭터 앞에 부채꼴로 펼쳐지고, 위쪽 띠에 지금과 다음 차례가 보입니다.

기본 화면은 종이 오리기 화풍입니다. 캐릭터와 소품은 색종이를 오려 붙인 그림이고, 집은 같은 화풍의 원화를 로우폴리 3D로 만든 그대로 보여 줍니다. 그 위에 그늘, 빛 번짐, 빛 입자 같은 빛 효과가 켜져 있습니다. 주소 끝에 `?air=off`를 붙이면 빛 효과와 소품이 없는 화면, `?look=ink`를 붙이면 건물에 테두리 선을 두른 화면, `?look=cartoon`을 붙이면 예전에 시험한 카툰 렌더링 화면으로 비교해 볼 수 있습니다.

카메라 구도는 비스듬한 탑뷰 50도입니다(앞·뒤·왼쪽·오른쪽 4방향). `?pitch=45`처럼 내려다보는 각도(30~80)를 바꿔 볼 수 있고, `?view=quarter`를 붙이면 예전 45도 쿼터뷰로 비교해 볼 수 있습니다.

## 기술

Three.js, TypeScript, Vite, Vitest. 배포는 Vercel을 쓰며(`vercel.json`), 배포는 요청이 있을 때만 합니다.

## 이전 3D 프로토타입

캐릭터까지 3D로 만들었던 이전 판의 코드와 모델은 이 정리 이전의 커밋 기록에 남아 있습니다.
기획 내용(세계관, 시나리오, 전투 규칙)은 위 문서와 `src/data/chapter1.ts`, `src/core/rules.js`로 옮겼습니다.

## 참고와 권리

- 그래픽과 연출 방식은 2000년작 RPG 「악튜러스」의 3D 배경 + 2D 캐릭터 방식을 참고했습니다. 원작의 캐릭터, 지도, 음악, 대사, 이미지는 쓰지 않습니다.
- 캐릭터와 배경 그림, 3D 모델은 이 프로젝트를 위해 새로 만든 것입니다.
- Three.js는 MIT 라이선스입니다.

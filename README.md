# 녹턴: 세 개의 서약

악튜러스의 반실시간 파티 전투에서 영감을 받은, 독자 세계관의 카툰 3D RPG 프로토타입입니다. 제1장 한 편(약 8~15분)을 구현했습니다.

## 현재 구현 · Character Edition 05

세 주인공을 컨셉 시트의 3등신 정면 도안에 맞춰 새 메쉬·골격으로 제작했습니다. 기존 heroes.mjs는 실행 경로에서 제외했습니다. 각 GLB에는 28개 관절, 피부 변형 가중치, 재질, 대기·걷기·달리기·기본 공격·고유 기술·시전·피격·방어·쓰러짐 9개 클립이 포함됩니다.

Kay Lousberg의 KayKit Adventures CC0 동작을 새 체형에 맞춰 재타기팅했습니다. 리시엔은 찌르기, 볼프는 한손 사선 베기와 내려치기, 에다는 주문 시전으로 연결합니다. 기본 동작의 관절 회전은 실제 게임용 클립에서 가져왔으며 의상과 꼬리의 보조 움직임을 별도로 구웠습니다. 캐릭터 외형과 메쉬·골격 설계는 이 프로젝트의 신규 제작물입니다.

전투는 접근 → 준비 → 접촉 → 복귀 순서로 재생하며 접촉 시 피해 수치와 체력 표시를 갱신합니다. 메뉴를 열면 전투 연출도 멈춥니다. 모델은 인물 화면과 atelier.html에서 회전, 동작 선택, 느린 재생, 구간 탐색, GLB 다운로드로 확인할 수 있습니다.

- dist/models-v5/: 새 모델 GLB 3종과 동작 출처·라이선스
- character-source-v5/: 신규 형상 설계, 골격, 재타기팅, GLB 생성기와 재현용 동작 데이터
- dist/characters-v5.mjs: 공용 모델 로더, 독립 골격 복제, 애니메이션 전환
- dist/performance-v5.mjs: 전투 동작·접촉·복귀 연출

GLB는 Blender 등에서 가져올 수 있습니다. 얼굴 표정, 개별 손가락 관절, 천 충돌 시뮬레이션, 장비 교체 시 외형 변경은 아직 포함하지 않습니다. 기록관·파수기는 기존 프로토타입 모델을 사용합니다.

## 이전 제작 기록 · Art Edition 02

### 캐릭터 모델 개선 · Art Edition 03

세 주인공의 모델을 다시 제작했습니다. 턱선과 눈꺼풀, 끝으로 갈수록 가늘어지는 머리카락과 갈기, 허리선이 잡힌 코트와 분리된 옷자락, 금속 견갑, 장갑의 손가락과 부츠 끈을 표현합니다. 무기 손잡이가 손바닥을 기준으로 연결되고, 팔꿈치가 움직이며 공격합니다. 피부·머리카락·금속의 재질을 구분하고 카툰 의상 명암과 함께 사용합니다.

인물 화면의 모델 창을 넓혔습니다. 드래그로 회전·기울기 조절, 휠로 확대·축소가 가능하고, 대기·걷기·공격 동작과 정면 보기 버튼을 제공합니다. 모델은 탐색과 전투에도 동일하게 적용됩니다. 초상화 4종은 Art Edition 02에서 제작한 것을 유지합니다.

## Art Edition 04

- 원작 공식 시스템 화면에서 확인되는 작은 캐릭터의 선명한 실루엣, 촘촘한 지면 재질, 높은 오브젝트 밀도를 기준으로 회색종 마을을 다시 설계했습니다. 건물은 2~3층 박공 지붕, 도머, 굴뚝, 아치 창, 화분, 목재 골조를 갖추고 시장·수로·다리·성문이 한 화면에서 이어집니다.
- `dist/stage.mjs`의 모듈형 마을 키트는 실제 3D 지오메트리로 골목, 시장 차양, 물레바퀴, 가로등, 나무 잎, 분수, 성문을 구성하고 정적 메시를 재질별로 묶습니다. `dist/art-04/material-atlas.png`는 석재·기와·회벽·목재 4분할 타일입니다.
- 캐릭터는 얼굴 UV에 새로 그린 눈·표정 재질을 투영하고, 직물에는 반복 직조 무늬를 입혔습니다. 리시엔의 머리카락은 가는 하이라이트 층, 볼프는 이마·볼·주둥이의 털 층과 황금 눈, 에다는 튜닉·고글·룬 장비로 구분됩니다. `dist/art-04/face-atlas.png`, `dist/art-04/wolf-face.png`, `dist/art-04/damask.png`가 적용 자산입니다.
- 제작 기준 시트는 `art-direction-04/characters.png`와 `art-direction-04/stage-kit.png`이며, 모든 생성 지시문은 `ART-PROMPTS-04.txt`에 기록했습니다. 이미지는 내장 `image_gen`으로 생성하고 실제 모델·스테이지 표면에 연결했습니다.

Art Edition 04 당시에는 제작 프로그램용 골격과 GLB 내보내기가 없었으며, 이 부분은 현재 Edition 05에서 새로 구현했습니다.

- 리시엔·볼프·에다·기록관 오린의 전용 대화 초상화 4종을 제작했습니다. 화자에 맞춰 이미지가 바뀌며, 동료 카드와 인물 화면에도 적용했습니다.
- 약 2.7등신의 실제 3D 캐릭터를 제작했습니다. 리시엔은 레이스와 루비 장식, 망토와 레이피어를 갖춘 귀족, 볼프는 주둥이·송곳니·꼬리와 강철 견갑을 갖춘 늑대 군인, 에다는 고글·공구 가방·마력 지팡이를 갖춘 룬 기공사입니다.
- 기록관, 일반 파수기, 보스의 모델도 교체했습니다. 카툰 명암과 윤곽선, 보행·무기 휘두르기·눈 깜박임·망토와 꼬리의 움직임을 구현했습니다.
- 인물·장비 화면에서 모델을 마우스 또는 터치로 좌우로 끌어 회전시킬 수 있습니다.
- 귀족 저택의 버건디 지붕, 공방의 물레바퀴와 배관, 동력로의 회전 봉인 고리를 추가했습니다.

초상화 원본은 `dist/art-02/`에 있습니다. 내장 이미지 생성 도구(built-in image_gen)로 생성했으며, 각 이미지의 최종 생성 지시문은 `ART-PROMPTS.txt`에 기록했습니다. 3D 모델은 실행 코드로 구성한 독자 모델입니다.

## 실행

Node.js가 설치된 환경에서 이 폴더의 `server.mjs`를 실행한 뒤 `http://127.0.0.1:4173`을 엽니다. 별도 패키지 설치가 필요하지 않습니다. 웹 서버로 `dist` 폴더를 제공해도 됩니다. HTML 파일을 직접 여는 방식은 브라우저의 모듈 보안 정책 때문에 지원하지 않습니다.

## 플레이 순서

1. 오른쪽 목표 버튼으로 기록관에게 이동 → E로 대화합니다.
2. 지원 세력을 선택하고 목표 버튼으로 동력로에 이동 → E로 조사합니다.
3. 적을 선택하고 동료의 차례마다 1~5 또는 행동 버튼을 사용합니다.
4. 첫 승리 후 장비를 강화하고 무기 종류를 바꿔 봅니다.
5. 동력로를 다시 조사해 보스를 처치하고 제1장 결말을 확인합니다.

WASD / 방향키 / 바닥 클릭: 이동. Q / R: 시점 회전. 휠: 확대·축소. I: 인물·장비. J: 여행 수첩. E: 상호작용. 저장은 브라우저별 로컬 저장입니다. 전투 승리, 선택, 장비 변경 시 자동 저장합니다.

## 구현 범위와 한계

- 실제 3D 정사영 마을, 2~3등신 카툰 캐릭터, 전용 대화 초상화, 보행·공격 간이 모션, 인물 모델 회전 보기.
- 세 종족의 상호 의존, 대화 선택, 일반 전투 1회와 보스전 1회, 선택에 따른 결말 문장.
- HP / BP / MP / 공격 / 마법 / 방어 / 민첩, 경험치·레벨, 캐릭터별 기술 2개, 회복·소생, 무기 교체, 무기·방어구 +3 확정 강화.
- 전투 중 자유 이동, 시전 취소, 복잡한 장비 인벤토리, 레벨별 스킬 해금, 장거리 탐험, 표정별 초상화, 배경음악·음성은 미구현입니다. 현재 모델은 프로토타입용이며 무기 교체 시 외형은 바뀌지 않습니다. 소리 버튼은 간단한 합성 효과음만 켭니다.
- Google Fonts를 제외한 실행 자산은 로컬에 포함됩니다. 폰트를 불러오지 못하면 시스템 한글 글꼴로 표시합니다. GPU 하드웨어 가속과 WebGL2가 가능한 최신 브라우저를 권장합니다.

## 원작 분석 출처

- [일본 발매사 공식 시스템 설명](https://www.falcom.co.jp/arc/system/): 명령 입력 중 정지하는 반실시간 전투, 민첩 기반 게이지, BP의 선행 소모·자연 회복·방어구 연계. 수치와 계산식은 이번 프로토타입의 독자 설계입니다.
- [공식 작품 소개](https://www.falcom.co.jp/arc/index2.html): 그라비티·손노리 작품, 선악과 황폐해지는 세계를 다루는 이야기.
- [2002년 그래픽 소개 기사](https://games.sina.com.cn/newgames/0203/03158315.shtml): 3D 배경과 2D 인물의 결합. 이번 프로토타입은 인물까지 3D로 제작했습니다.

원작의 캐릭터, 지도, 음악, 대사, 이미지 파일을 복제하거나 포함하지 않습니다. 늑대인간 군단은 가상의 군사 국가이며 역사적 정권의 상징을 사용하지 않습니다.

## 파일 구성

- `dist/core.mjs`: 상태, 성장, 전투와 장비 규칙.
- `dist/world.mjs`: 3D 환경·경로 탐색·카메라.
- `dist/actors.mjs`: 캐릭터 모델·동작·인물 화면 회전 보기.
- `dist/heroes.mjs`: 과거 Edition 04 보관 소스. 현재 주인공 실행 경로에서는 사용하지 않습니다.
- `dist/art-02/`: 대화용 초상화 원본 PNG 4종.
- `ART-PROMPTS.txt`: 초상화 최종 생성 지시문과 사용 도구.
- `dist/game.mjs`: 대화, 화면, 입력, 저장.
- `dist/style.css`, `dist/art.css`, `dist/index.html`: 게임 화면.
- `dist/vendor/`: Three.js 0.160.1 및 MIT 라이선스.

연구 확인일: 2026-09-11. 본 분석은 공개된 공식 설명과 당시 기사에 근거하며 원작 실행 파일을 직접 플레이한 검증은 아닙니다.

## 동작 검증

프로젝트 폴더에서 `node tests/test-core.mjs`와 `node tests/test-v5.mjs`를 실행합니다. 새 GLB를 실제 로더로 읽어 관절 수, 가중치 정규화, 움직이는 무릎·팔꿈치, 스킨 변형, 모델별 독립 골격, 공격 후 대기, 사망 자세 유지, 접촉 전 피해 방지, 일시 정지 및 광역 공격의 단일 접촉을 검사합니다. 로컬 브라우저에서 초상화·동작 확인 화면, 탐색과 첫 전투도 확인했습니다.
